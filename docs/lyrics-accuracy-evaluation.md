# 가사 정확도 확인 방법

자동 선택 기준은 88점입니다. 제목 유사도(최대 45), 참여 가수(최대 35),
재생 시간(최대 15), 앨범(최대 5)을 비교합니다. 곡 ID로 조회한 Spotify 응답은
요청한 곡 ID와 연결합니다. 다른 Live/Remix/Instrumental 등의 버전, 누락된
참여 가수, 3초를 넘는 재생 시간 차이는 점수 계산 전에 제외합니다.
싱크 가사도 실제 LRC 타임스탬프와 곡 길이를 확인한 뒤 선택합니다.
비슷한 점수의 같은 공급자 녹음 버전이 남으면 자동 선택하지 않습니다.

## 실제 음악으로 평가하기

1. 자주 듣는 30~50곡을 고릅니다. 한국어/일본어/영어, 공동 작업곡,
   같은 제목의 다른 가수, 라이브/리믹스/리마스터, 가사가 없는 곡을 포함합니다.
2. 검색 변경 전후를 **같은 곡, 같은 공급자 응답 또는 같은 기간**으로 비교합니다.
   캐시를 사용하는 결과와 처음 검색하는 결과를 따로 기록합니다.
3. 아래 CSV 양식에 현재 곡 정보와 정답 가사 공급자/ID를 입력합니다.
4. 자동 선택 결과를 직접 확인합니다. 곡 일치와 싱크 일치를 별도로 평가합니다.
   싱크는 시작/중간/끝 구절에서 확인하고 허용 오차(예: 1초)를 먼저 정합니다.
5. 자동 선택 정확도 = 정답 자동 선택 / 전체 자동 선택.
   검색 성공률 = 정답 자동 선택 / 전체 평가 곡. 오매칭 수와 수동 선택 수,
   공급자 오류도 함께 기록합니다. 점수는 확률이 아니며 실제 데이터로 조정해야 합니다.

```csv
case_id,title,artists,album,track_id,duration_ms,expected_provider,expected_id,selected_provider,selected_id,match_score,result,sync_start_error_ms,sync_middle_error_ms,sync_end_error_ms,notes
001,,,,,,,,,,,,,,,
```

result: correct / wrong_song / wrong_version / no_match / provider_error.
일반 가사에는 싱크 오차를 기록하지 않습니다. 실제 가사 본문이나 API 키는
평가 파일에 넣을 필요가 없습니다.

## 자동 회귀 테스트

LyricsRegressionTest와 LyricsAccuracyTest는 유니코드 캐시 키, 후보 순위,
잘못된 녹음 버전, 공동 작업곡, Spotify ID, 일반/싱크 가사 구분과 LRC 파싱을
검증합니다. 40개의 녹음 버전 조합은 합성 데이터입니다.
이 테스트 통과를 실제 곡 검색 정확도 수치로 해석하지 않습니다.
