# 관리자 검색 진단 로그

검색 진단은 항상 기록하지만 일반 대시보드에는 관리자 버튼을 표시하지 않습니다. 대시보드 상단의 작은 제목 **스마트 화면보호기**를 **5초 안에 정확히 7번 누른 뒤, 3초 안에 같은 제목을 길게 누르면** Android 기기 인증을 시작합니다. 횟수·시간을 틀리거나 앱을 벗어나면 처음부터 다시 해야 하며, 진행 횟수나 진입 안내는 일반 화면에 표시하지 않습니다.

숨겨진 동작은 실수로 들어가는 것을 막는 진입 장치입니다. 로그 열람 권한은 별도로 Android의 기기 화면잠금 PIN·패턴·비밀번호 인증으로 확인합니다. 기본 관리자 비밀번호나 인증 우회 버튼은 없습니다. 화면잠금이 없는 기기에서는 먼저 화면잠금을 설정해야 합니다.

## 관리자 세션

- 인증 성공 후에만 읽기·비우기를 허용합니다. 저장소 API도 세션을 검사하므로 화면만 숨기는 방식이 아닙니다.
- 창을 닫거나 앱이 백그라운드로 이동하면 즉시 잠깁니다. 세션은 최대 5분이며 앱 재시작·화면 재생성 후에는 다시 인증해야 합니다.
- 로그 창은 Android의 보안 창 옵션을 사용해 스크린샷·최근 앱 미리보기 캡처를 제한합니다.
- 일반 화면에는 로그 내용이 나타나지 않습니다. 외부 앱으로 내보내는 진단 Activity·ContentProvider·공유 기능은 추가하지 않았습니다.

## 기록 내용

| 단계 | 확인할 내용 |
| --- | --- |
| `MEDIA_DETECTED` | 감지한 제목·아티스트·곡 길이·메타데이터 가사 유무 |
| `SEARCH_START`, `CACHE_HIT`, `METADATA_USED` | 검색 시작, 기존 캐시 사용, 음악 앱의 가사 사용 |
| `QUERY`, `CANDIDATES` | 정리한 검색어, 후보 수와 통과 수, 제목·가수·길이·버전 불일치 등 제외 이유 |
| `HTTP_RESPONSE`, `HTTP_FAILURE` | 제공자 호스트, HTTP 상태 코드, 요청 소요 시간, 예외 종류 |
| `MATCH`, `SUCCESS`, `NO_MATCH` | 가사 선택·조회 성공·실패 |
| `SOURCE_TIMEOUT`, `RETRY`, `CANCELLED`, `FAILURE` | 제공자 시간 초과, 재시도 예약, 요청 취소, 예외 종류 |

시간은 UTC로 표시하며 관리자 화면에서는 최근 200건을 최신 순으로 봅니다. 검색어와 곡 제목·가수는 기록하지만, 가사 본문·앨범 이미지·응답 본문·헤더·전체 요청 URL·API 키는 기록하지 않습니다. 오류 메시지나 스택 트레이스 대신 예외 클래스만 남깁니다. 허용된 필드만 저장하고 알려진 키·URL 패턴과 제어 문자를 제거합니다.

로그는 앱 전용 `noBackupFilesDir/lyrics-diagnostics`에 JSON Lines 형식으로 저장하므로 Android 자동 백업·기기 이전에 포함되지 않습니다. 최대 64KiB 파일 두 개를 순환 사용하며, 메모리 대기열은 128건으로 제한합니다. 대기열이 가득 차면 새 진단 이벤트를 생략합니다. 파일 쓰기는 단일 IO 작업에서 처리하고 저장 실패가 가사 검색을 중단시키지 않도록 했습니다. 캐시 비우기와 진단 로그 비우기는 별개입니다.

## 휴대폰에서 확인하는 순서

1. 업데이트 APK를 설치하고 음악 앱에서 문제가 나는 곡을 재생합니다.
2. 자동 검색이 끝나거나 실패할 때까지 잠시 기다립니다. 수동 검색으로 성공한다면 그 검색도 한 번 실행해 비교 기록을 남길 수 있습니다.
3. 대시보드의 작은 제목 **스마트 화면보호기**를 5초 안에 정확히 7번 누르고, 3초 안에 같은 제목을 길게 누른 뒤 기기 인증으로 로그를 엽니다. 인증 중 잠깐 앱이 백그라운드로 이동하는 것은 정상입니다.
4. `MEDIA_DETECTED`와 `QUERY`로 검색 대상을, `CANDIDATES`로 제외 이유를, `HTTP_*`로 서버 오류·연결 문제를 확인합니다.
5. 추가 검색 후에는 **새로고침**, 기록 삭제는 **로그 비우기**, 종료는 **닫고 잠그기**를 사용합니다.

자동 테스트는 인증 실패·미설정 화면잠금·만료·잠금 후 접근 차단, 파일 순환·지속 저장·민감 필드 제외·저장 오류 격리를 검증합니다. 실제 Android 기기에서 시스템 인증 화면의 성공·취소와 앱 전환 동작은 별도 실기기 확인이 필요합니다.
